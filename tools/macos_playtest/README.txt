HelloOgre3D macOS 试玩包

系统要求：macOS 15.6 或更高版本，Apple Silicon Mac。

启动方式：双击 HelloOgre3D.app。程序会自动从包内加载配置、Lua 脚本和 media 资源。

Sandbox19 操作：
- Enter：开始任务；结算后重开
- W / S：沿指挥官朝向前进 / 后退；A / D：相对指挥官朝向侧移；R 换弹
- 正常游玩时移动鼠标：转镜头并让指挥官跟随朝向；左键或 Space 开火；滚轮缩放
- 按住 Alt：临时显示鼠标，可点击 HUD、左键拖框选择友军、右键对敌人集火或命令友军移动
- 1 / 2、Tab：选择友军；Q / E：辅助转镜头
- F：集火
- T：撤退并守住位置；G：在指挥官周围集合；X：取消指令
- Esc：暂停；I：行为观察；F3：导航调试

这是内部试玩构建，使用本机临时签名，未做 Apple 公证。
