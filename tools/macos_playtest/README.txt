HelloOgre3D macOS 试玩包

系统要求：macOS 15.6 或更高版本，Apple Silicon Mac。

启动方式：双击 HelloOgre3D.app。程序会自动从包内加载配置、Lua 脚本和 media 资源。

Sandbox19 操作：
- Enter：开始任务；结算后重开
- W / S：沿指挥官朝向前进 / 后退；A / D：相对指挥官朝向侧移；R 换弹
- 正常游玩时移动鼠标：转镜头并让指挥官跟随朝向；左键或 Space 开火；滚轮缩放
- 按住 Alt：临时显示鼠标，可点击 HUD、左键拖框选择友军、右键对敌人集火或命令友军移动
- 1 / 2、Tab：选择友军；Q / E：辅助转镜头
- F：集火
- T：撤退并守住位置；G：在指挥官周围集合；X：取消指令
- Esc：暂停；I：行为观察；F3：导航调试

人工核对（请用实际键鼠和扬声器完成一局）：
1. 开始后连续转动鼠标，交替按 W / A / D、左键或 Space；观察镜头、身体朝向、移动和枪口是否一致。
2. 按住 Alt 点击 HUD、拖框选友军、右键下令；松开 Alt 后确认鼠标恢复转镜，命令在队友状态中可见。
3. 暂时切到别的应用再返回；首次点击应只恢复鼠标捕获，不应误开火或下令。
4. 按 Esc 暂停并恢复，完成任务后按 Enter 重开，确认新一局仍能转镜和下令。
5. 用扬声器分辨开火、命中/受伤、命令及结算提示；检查音量和静音设置是否符合预期。
若有异常，请记下步骤、当时的画面或声音以及是否可重复。此清单需要真人反馈，自动回放不代表人工通过。
