# 中间产物默认放本地，别发 Artifact/claude.ai

类型：feedback

诊断图 / 可视化 / 临时报告等中间产物，**默认写到本地**（项目内 `tmp/` 或用户指定路径），做成**自包含 HTML/文件**，用浏览器或编辑器直接打开即可。

**不要默认用 Artifact 工具发布到 claude.ai**——那需要联网 + 登录访问，对本地 VSCode 开发工作流不合适，用户明确反感（原话：“你不应该是放到本地吗，怎么把这东西放网上了呀，还申请请求访问”）。

**例外**：只有用户**明确要分享**时才用 Artifact。

**怎么做**：自包含 HTML（数据内联 / canvas 渲染）写到 `tmp/`，告诉用户本地路径 + “浏览器直接打开、离线”。相关：[[run-and-diagnose]]（自己跑自己看，别甩给用户）。
