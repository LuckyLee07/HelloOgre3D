2026-09-13 在 Sandbox3 的 30Hz 仿真/60Hz 最终显示帧上，以较低脚为支撑，最多 0.12m 世界水平锚定，仅旋转同侧大腿并保持脚朝向。35 个有效步的滑移中位数从 2.61cm 降到 1.95cm，但 P90 从 9.12cm 升到 9.63cm，脚高上限从 10.16cm 升到 11.84cm；侧移画面没有明确收益，代码撤回，Release 程序哈希恢复原值。原始日志/截图在本地 `tmp/goal-p3-foot-lock-20260913/`，汇总见 [P3 分轮记录](../dev-design/plans/2026-09-13-sandbox19-p3-iteration.md)。

求解器从未修正的显示姿态选较低脚，但输出脚高在单关节校正后变化，按输出姿态测得的切换时点也相对基线改变；后续须明确接触窗口，检查左右换脚与高度，再考虑膝/踝约束或专用站立侧步。只看中位位移会漏掉大滑移与离地风险。
