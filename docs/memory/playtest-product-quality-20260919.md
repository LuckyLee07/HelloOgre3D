# 作者试玩未认可当前产品完成度

2026-09-19 作者实际试玩后反馈：场景、模型和开火射击操作整体效果一般，仍有明显 Demo 感，希望形成精致的小产品/小玩法。

作者随后明确补充：不仅是玩法，场景、美术等也需要同步升级。后续设计与实施要把角色、环境、材质光照、动作/特效、声音和 UI 作为同一精修样段交付；不能把改玩法、换镜头或减少内容当作视觉质量提升。

作者明确表示直接操控射击和小队战术指挥均可接受，优先选择最容易做出完成度与特色的方案。作者随后明确要求“根据这个重新设计草案的规划开始升级”，已授权按双机交叉行动方案实施。先完成一个玩法与美术联合样段。首包启动后作者进一步要求“继续后续的升级”，授权按草案推进三关与产品衔接；这条继续指令不等于对每个品质分项的主观认可。

后续不能把问题只描述为“待作者试玩”，也不能用旧 P0 方向认可、自然通关或局部视觉 PASS 代替当前整体体验认可。此次未说明具体平台、所有输入动作或听感分项，不追溯改写历史未验证项。

本轮设计建议见 ../dev-design/specs/2026-09-19-relay-microgame-design.md；实际任务状态仍以 ../cycle-01.md 与 ../backlog.md 为准。

2026-09-19 第二包反馈进一步明确为“点地图没有反应，不知道怎么移动/开火”。首次操作的可发现性是已确认的问题，不能只给快捷键说明或以内部回放通关判定可玩；需要地图点击本身生效、排队/执行反馈清楚，并用实际窗口验证完整操作。
