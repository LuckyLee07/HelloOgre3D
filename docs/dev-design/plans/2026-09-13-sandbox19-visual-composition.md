# Sandbox19 构图与院区层次续办

日期：2026-09-13。状态：本轮局部视觉与现有玩法回归已完成；P3 总体验仍未验收。

## 目标与取舍

对照批准的概念稿与当前实机，开场中央地面过空，第二波推进到院区时两侧原有长掩体已在镜头后方，敌人到门面之间缺少低层结构；入口画面右侧的西绕行墙在棚下接近黑块。保持已验证的直路、西绕行与 MiniGame 式鼠标控制，不以相机取景掩盖布局问题。

同一 macOS arm64 Release、1280×800、固定回放先采 8/30/65/80 秒基线。试过 6.0m 后距/3.0m 高、眼高 1.5m：主角脚部压到下方命令栏；又试 6.2/3.1、眼高 1.2m：脚部避开 HUD，但中继站上部被裁且角色与敌人的空白没有缩小。两档均撤回，最终继续使用原 6.5/3.2、眼高 1.5m 镜头。右侧黑块经分侧材质试验定位为世界坐标西侧绕行墙；误调亮的东服务区已撤回。随后侧视角发现首档高明度材质使受光端面红通道截顶，最终收为 `1.35 1.32 1.21`。

## 实施

- 现有网格生成器增加 2.4m 短倒角掩体变体，沿用 `Relay/Cover` 与同网格 Bullet 凸包。两件位于院区 `x=±6.2,z=33.9`，在第二波敌人后侧形成低层轮廓；高/低补给箱各一件放外肩。中轴 `x=0` 到门前及西绕行仍无新增阻断。
- 西绕行墙使用独立 `Relay/BypassWall`，只提高这片原本近黑的墙面明度；不增加灯光或阴影 pass。左侧东服务区仍用原材质。
- 产品自检增加新短掩体真实射线与院区门前水平净空；HUD 院区任务副标题将 `Hostiles remaining` 收为 `Hostiles`，避免 1600×900 下敌人数被裁。
