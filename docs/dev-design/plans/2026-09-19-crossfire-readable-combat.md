# Crossfire 战斗可读性与场景精修

依据 [Computer Use 实际试玩](../reviews/2026-09-19-crossfire-computer-use-review.md)，用户已同意实施。范围为现有三关的操作、美术与反馈，不扩展关卡数量。

## 已实现行为

- 选机或指向敌人时，从真实枪口显示当前射界，保留指定目标名称，同时说明正面盾、设备、友军、活单位或残骸的第一处阻挡。实体处截断实线，后半段虚线提示原目标；换位由玩家决定。旋转中显示“瞄准中”，移动中说明抵达后自动开火，感知尚不能锁定时不会承诺可命中。
- 落点使用真实表面拾取，再检查地面范围和导航。点击设备会说明设备名称，不能点穿机器生成其后方路线；四条维护边界与可下令范围对齐。地面悬停显示落点和路径，VEGA/ROOK 使用不同颜色及编号。
- 每关关键战术提示独立于短时操作确认，暂停、执行、选择均不会覆盖。敌人名称稳定，护盾状态另列。结算显示本局有效侧击与护盾挡弹次数。
- 镜头按实际窗口及 HUD 安全区容纳战场，两机模型更大。VEGA 为青绿尖头与 V 标，ROOK 为钢蓝宽肩与双条标；原刚体、枪口及尺寸保持。哨卫有朝向箭头和 120° 盾带，死亡实体变为暗灰残骸，继续保留原碰撞体。
- 中文操作、菜单、设置、帮助与结果通过独立 Noto Sans SC OFL 字库接入既有 Gorilla。保留原 DejaVu ASCII，未修改第三方渲染器/FGUI。文本按实际字宽换行，关键提示及标题加深色底，单位标签避让；所有机体点击优先于名称标签，避免邻机标签抢选。

## 实现与约束

主会话集成 Sandbox20/反馈逻辑、构建和唯一运行窗口；三个独立代理分别负责物理查询与局部绑定、HUD、场景资产。共享构建与运行串行。

`WeaponComponent:GetMuzzlePosition()` 返回独立 GC Vector3；`TraceProjectile` / `PickSurface` 借用并就地写出 hitPoint，返回首个对象 ID、0（清晰）、-1（未知/无效）。输入输出可别名，查询前刷新 Bullet AABB，保证暂停中创建或移动的物体也可命中。头文件、`.pkg` 头文件引用、局部绑定与 Lua 调用同步，未全量生成 tolua；没有 ABI 布局变更。

射界是当前物理快照，不是抵达后的保证。连续 capsule sweep 与实际弹丸共用尺寸，但未重演每个物理步；Bullet 高速 CCD 使用半径 .01 m 的球，capsule 鼻端可能保守地提前约 .14 m 报接触。预览忽略飞行弹丸，实弹仍可能互相抵消；单位旋转/移动也会改变结果。AI 感知仍使用 render AABB，与物理 hull 不同，因此单独保留“尚不能锁定”的反馈。

字库来源、授权和文案扩展流程见[字库说明](../../../media/fonts/crossfire/README.md)；原创网格及相机/边界说明见[模型来源](../../../media/models/crossfire/SOURCE.md)。HUD 图元由现有 UIManager 持有并复用；Lua 只保存值与封装 handle，不新增 FGUI callback/ref。

## 完成范围与保留项

本轮完成战斗可读性、中文上手、镜头与双机/护盾/残骸的联合升级，以及具体侧击/挡弹统计。未实现点击提示自动定位阻挡者或首次受阻自动暂停；提示与场内阻挡标记已直接可见，不自动替玩家决策。未扩展关卡数量，也未重做三关节奏或追加完整材质/环境动态。

原生试玩第一轮曾因工具往返期间长时间执行而损失 VEGA，在结算前暂停后重试；不记为正式失败成绩。Computer Use 的点击间隔不代表真人反应速度；扬声器听感与 Windows 构建/运行未验证。作者对整体场景、模型、操作和声音的主观验收继续保留，不将技术 PASS 等同于精致产品已完成。
