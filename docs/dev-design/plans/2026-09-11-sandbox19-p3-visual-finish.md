# Sandbox19 P3 视觉体验收口

日期：2026-09-11
状态：已完成

## 目标

在已完成的中继站玩法、相机/HUD 结构和导航布局上，完成一轮可在当前 Ogre 渲染链真实兑现的视觉收口：降低程序方块感，强化 relay 终点身份与场景层次，使射击、命中和队伍受伤在正常镜头下可辨认。此次不以替换角色骨骼模型或新建 PBR/后处理管线为完成前提。

## 实施任务

### 1. 专用表面与光照

- 文件/层：`media/textures/sandbox19/`、`media/materials/sandbox19_relay.material`、`sandbox19_scene.lua`。
- 行为：新增项目专用 relay 面板表面；区分基座、面板、结构边和信号灯；调整太阳方向，让主要交战视角能读到 relay 正面与角色轮廓。
- 验证：纹理和材质在 OpenGL/macOS 实际加载，无黑面、缺材质或强烈接缝；目标视角不再把 relay 正面压成整块暗色。

### 2. 环境轮廓与终点身份

- 文件/层：`bin/res/scripts/samples/sandbox19_scene.lua`。
- 行为：在现有建筑和外围墙体上增加贴附式面板、压顶、支撑、设备组与信号构件；装饰体嵌入既有实体或位于路线之外，不改变中央主路、西侧绕行和集合区。
- 验证：入口视角可辨认前景掩体、中段服务区、relay 门面与屋顶信标四层；原导航、碰撞射线和出生点检查保持通过。

### 3. 交火与受伤反馈

- 文件/层：`media/particle/`、`media/materials/particles.material`、`sandbox19_hud.lua`、`Sandbox19.lua`。
- 行为：提高物理子弹曳光和碰撞火花在 8–12 米交战距离的可见性；指挥官受伤时显示短暂屏幕边缘提示，队友受伤时只闪对应队友卡，不从声音或最终动作反推受伤来源。
- 验证：反馈由真实弹丸/HP 差分驱动，暂停、重开和死亡后不残留；不遮挡任务、命令和目标标记。

### 4. 运行验收与文档同步

- 已重新生成 Xcode 工程并完成 macOS arm64 Release 构建；当前机器没有 Lua 5.1 可执行文件，改用 `/usr/local/bin/luac`（5.3）完成三个改动脚本的解析检查，并把 5.1 未执行单列为限制。
- 已在真实 macOS 图形会话运行 Sandbox19 产品 fixture 与 `Sandbox19/6/7/8` smoke，并读取日志。当前 Apple 普通窗口路径在 `ClientManager` 中固定为 1280×720，因此本轮取得新的 720p GL 实机图；1920×1080 继续引用上一轮 Windows D3D9 证据，不把未发生的 macOS 1080p 抓帧写成已完成。
- 已更新视觉复盘、cycle/backlog、模块文档与文档索引；人工持续输入手感、扬声器听感、动态窗口和更高阶资产继续单列，不写成 PASS。

## 完成条件

- relay 正面、材质分区、边缘结构与信号构件在正常战斗镜头中清楚可见，场地不再主要由无细节长方体组成。
- 射击与命中瞬间可辨认，指挥官/队友受伤反馈准确且短暂。
- HUD、路径、碰撞、任务闭环、暂停和重开不回归。
- 当前 macOS Release 运行和实际截图形成新的本轮证据；无法执行的平台保持未验证。

## 完成记录

- relay 主体已经使用项目专用面板纹理，正面增加结构框、檐口、设备、门体强调与青/琥珀信标；外围墙、侧墙和掩体增加压顶，主路和两条导航路线不变。
- `Bullet` 改为短寿命世界空间曳光，`BulletImpact` 收敛为暖色命中火花；`WeaponComponent` 在真实发射入口创建短暂 `MuzzleFlash`，Sandbox19 指挥官和队友的受伤提示由真实 HP 差分驱动并在 220ms 后消退。
- macOS arm64 Release 构建通过；最终产品 fixture 为 `status=PASS reason=evidence-complete`，`Sandbox19/6/7/8` smoke 全部 PASS。新纹理在 Apple M1 Pro / OpenGL 4.1、1280×720 实际加载，门面、指挥官受伤边缘和世界空间曳光均有实机截图。
- 本计划约定的“当前渲染链可兑现的视觉收口”已经完成。替换角色模型、植被、PBR/后处理、人工手感/扬声器听感和动态窗口不属于本计划完成前提，继续保留在 P3 总体验边界中。
