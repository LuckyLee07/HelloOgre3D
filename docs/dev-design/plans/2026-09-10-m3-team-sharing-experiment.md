# M3 团队信息共享对照实验计划

状态：已完成

## 目标

在 Sandbox12 的受控三单位场景中回答：A 直接看到敌人而 B 被实体遮挡时，团队共享是否会让 B 读取 A 的事实并移动；敌人离开视野且事实过期后，B 是否停止依赖旧信息。

## 设计

- 固定 A、B 为同队，敌人为另一队；在导航网格构建前创建一处实验遮挡体。A/B 都朝向敌人，A 从侧方直视敌人，B 的视线穿过遮挡体。
- 使用 M3 专用最小行为树：只响应显式移动目标或待机。保留 C++ 感知调度，排除随机巡逻、追击和射击，使 B 的位移可归因到团队共享路径。
- 唯一对照变量由 runner 通过 `HELLO_EXPERIMENT_CASE_VALUE` 传入：共享开启时允许直接目击发布和队友消费，关闭时两者均不发生；布局、seed、调度、TTL 和目标脚本保持一致。
- 敌人在固定时刻由场景脚本移动到 A/B 身后。该受控位置变化会明确记录为 `direct_state_mutation=true`，只用于制造“离开视野”，不作为自然移动证据。
- 结构化事件记录 ready、视野隔离、发布、消费、B 首次位移、敌人离开视野、事实过期和观察窗结束。观察窗同时要求团队事实、支援意图、AI 移动目标和路径均已清理，并记录事实过期后的累计行程、最大偏移与末速度；MoveAction 在下一次更新或抢占清理阶段都能处理已删除的 `movePos`，相同目标重入而 path 为空时会重新寻路。

## 实施

1. 在 `sample_presets.lua` 增加独立 `team_sharing_experiment` preset 与三点布局，不改变 Sandbox12 默认 preset。
2. 在 `Sandbox12.lua` 增加仅由实验 preset + run id 激活的遮挡、角色控制、共享开关、生命周期清理和事件输出。
3. 将 `run_ai_experiment.py` 扩为兼容声明式事件契约和指标，同时保持既有 Sandbox19 M2 manifest 可用；补解析契约测试。
4. 增加版本化 M3 manifest，执行三 seed × 每条件三次、交替顺序的 18 局比较。
5. 按实际证据同步实验记录、cycle/backlog、模块文档和索引。若视野隔离或过期停止不成立，保留失败产物并修正场景或真实链路，不把配置存在当作行为通过。

## 验收与验证

- 共享开启：A 直接可见、B 直接不可见且确由遮挡体阻断；A 发布；B 从 A 消费；B 有可测位移；过期后事实、支援意图和移动目标均清理，随后位移在容差内。
- 共享关闭：同一视野条件成立；无发布、消费或共享移动；B 位移在容差内。
- Lua 5.1 语法、Python 单元测试与 dry-run、manifest/registry/链接与 CRLF、`git diff --check` 通过。
- 使用 Windows Release x64 二进制后台静音运行 Sandbox12；该 sample 没有 PlayerController，InputReplay 由 manifest 显式选择在首个更新循环开始计时并负责退出。这是内部合成场景证据，不替代人工输入、手感、听感或 macOS 验收。
