# Sandbox19 环境视觉深化计划

日期：2026-09-11
状态：已完成

设计：[Sandbox19 环境视觉深化设计](../specs/2026-09-11-sandbox19-environment-visual-design.md)

## 任务

- [x] **E1 差距与资源审计**：核对当前实机、目标稿、天空材质、可用模块模型和导航边界；确认 HUD 已不是主要差距。
- [x] **E2 专用荒漠天空盒**：生成无建筑的 360° 远山全景，转换为六面图，接入 `Relay/Sky` 并在 D3D9 检查朝向与接缝。
- [x] **E3 院区轮廓重构**：降低外围天际线，重组入口棚架、低掩体、设备组和 relay 主楼；保留主路、西侧绕行及出生/集合锚点。
- [x] **E4 材质与光照收敛**：增加风化混凝土表面、灰绿设备和少量识别带，调整环境光与方向光，减少平面泛白和重复贴片。
- [x] **E5 运行与视觉验收**：Lua 5.1、资源加载、导航/碰撞/产品自测、720p/1080p 截图与目标稿对照；记录实际 PASS、FAIL 和剩余 P3 差距。
- [x] **E6 文档同步**：更新当前周期、backlog、视觉复盘、设计图和实机图；只按真实证据调整状态。

## 依赖与边界

E3 依赖 E2 暴露远景后再判断墙高和 relay 轮廓；E4 与 E3 共用实机迭代。环境内容没有新增 Lua 绑定；为满足后台验证不抢占前台窗口的追加要求，Windows D3D9 适配增加了局部 `noActivate` 创建参数，自动启动器同步改用这一入口。自动输入能验证链路与截图，不能替代人工手感。
