# Sandbox19 场景资产与地表升级

日期：2026-09-12
状态：本轮已完成并通过当前平台验收。沿用当前 checkout，在前轮成果基础上完成视觉升级。

## 目标与判断

对照已批准概念稿和本轮新实机，优先改善占画面大部分的地表、方盒掩体及稀疏设施。角色/武器绑定和镜头保留上轮修复。

## 工作项

- [x] 同一 1280×720、隔离输入路线采集开场/推进/中继站三阶段新基线，记录二进制与配置。
- [x] 地表：项目专用 GL/HLSL 材质，物理尺度板缝、克制面板差异和表面细节；不增加 floor 刚体或修改导航。
- [x] 三维资产：自制带倒角的混凝土掩体与补给箱，使用可复现网格生成脚本、Ogre 原生 mesh、多材质分区与已有表面纹理；保留来源说明。替换原六组掩体，在其外侧组织近/中/远补给组。
- [x] 多角度迭代，核对形体/材质/阴影/贴地和视线；需要的实体均用实际网格生成 Bullet hull。
- [x] Lua 5.1、资源载入、真实截图、产品 fixture 导航/碰撞和自然对局/命令/重开；读取日志。影响共享 C++ 时追加 Release 及 Sandbox6/7/8。测量同条件帧耗时。
- [x] 更新文档与实际 P3 状态，保留仍缺的角色动画资产、足底 IK、Windows 和真人手感验收。

## 边界

新资源不使用第三方品牌或未经许可模型。场景对象仍由 ObjectManager 清理，Lua 不持有额外引擎裸指针；不扩展通用 PBR/关卡工具。Windows HLSL 进行静态同步，本机无法作为 D3D9 运行验收。

## 最终实现与取舍

- 六组掩体用真正倒角网格替换带深绿色盖板的方盒；保持原 4.2m 长、1.25m 高，补小拉结孔，主体沿用现有混凝土 albedo/normal。
- 新增六个高箱和六个低箱，布置在三段掩体外肩及旁侧；单个箱体有六类 submesh 材质、倒角、加强筋、盖缝、脚垫、锁扣、把手及简化 ID 条。原生网格由[生成器](../../../tools/generate_relay_meshes.py)直接输出，[manifest](../../../media/models/sandbox19/manifest.json)记录米制边界。封闭实体的 Bullet hull 从同一顶点数据生成。
- 地面专用 `relay_ground.program` 与 GLSL/HLSL 按世界坐标铺设 2.4×3.2m 错缝板；采样已有 v3 albedo 单板内部，轻微面板明度变化与接缝积尘。`fwidth` 控制窄缝像素覆盖，远处逐渐减弱。沿用现有地面刚体与方向阴影；没有给地表纹理伪造物理起伏或 PBR 数据。
- 棚顶改浅暖材料，设施压顶减少绿色，relay 顶层设备房改混凝土色；没有增加大块建筑或改动主路、绕行的端点。
- 涂层磨损由内置 ImageGen 全新生成，实际 1254×1254 RGB，使用原始输出乘以箱体材料 tint。未添加第三方模型；已有 Nobiax 资产与项目生成表面的来源继续保留。[网格来源](../../../media/models/sandbox19/SOURCE.md)、[贴图来源和最终提示词](../../../media/textures/sandbox19/SOURCE.md)。

第一版地板的深色网格在远处抢视觉，已收细、降低对比并做覆盖衰减；失败图保留在 `tmp/experience-fixes-20260912/upgrade-first`。初次近景回放鼠标字段错误，被 InputReplay 明确拒绝；`upgrade-second` 超时无图，不计为 PASS，随后使用合法字段的 `upgrade-second-valid` 才作为导航视图证据。

## 性能

同一冻结的 Release 可执行文件，在独立运行目录中只选择旧/新 `sandbox19_scene.lua` 和材质。1280×720，19s 固定交火输入，禁物理键鼠，关截图，逐帧日志阈值 0.1ms，剔除前 5s。ABBA 顺序，二进制 hash 完全一致；原始日志位于 `tmp/visual-upgrade-20260912/paired-v2-*`。

## 剩余差距

这次可见收益集中在地面、掩体形体与补给箱近中景，近门 60s 机位的改善较小。整体设施仍明显使用方块和重复模块；角色/枪械轮廓、站立侧移动画与足底接地尚需更合适的成套资产，当前光照也未达到概念图中的材质响应与软阴影。没有恢复失败的草卡，也没有把局部资产升级记作 P3 总体验完成。Windows、新增资源的真人操作观感及人工听感继续保留。
