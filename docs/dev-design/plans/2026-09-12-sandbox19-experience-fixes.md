# Sandbox19 战斗与操作体验修复

日期：2026-09-12
状态：本轮核心修复已实现并完成当前平台验收；P3资产与跨平台边界仍保留。
依据：[体验审计](../specs/2026-09-12-sandbox19-experience-audit.md)。保留前轮视觉工作区。

## 目标与范围

恢复真实枪火/命中反馈，修正物理移动与动画不一致，改善跟随相机的主动转向、瞄准参考和遮挡，校正 Release 构建基线。完成这些后在真实战斗画面中判断并处理代表性场景的主要可读性问题。现有 AI 决策 sample 和 Sandbox19 命令/重开仍须运行。

## 工作项

- [x] 粒子：显式 GLSL/HLSL 程序保留粒子颜色/透明度；复核枪械附属材质。真实物理子弹与接触点驱动反馈，撤除穿墙的独立长曳光；用实际近/远碰撞截图取证。
- [x] 动画：明确射击/待机停步合同；真实水平速度驱动移动动画，组合移动与射击；统一 shoot_fire 时点，核对取消、死亡、重开。C++/Lua 接口只局部同步。
- [x] 相机：中键拖动偏航/俯仰，Q/E 辅助；主动旋转不经过平移弹簧，移动与枪向使用同一参考。加入静态障碍体积探测，并把显示跟随与物理仿真时钟分开，保留物理真源。
- [x] 构建：从 Premake 真源修正 Xcode Release 依赖；生成工程，因类布局变化 clean rebuild 主程序；对照阴影/粒子同条件测量。
- [x] 整合：Lua 5.1、当前平台 Release、Sandbox6/7/8/19；相机释放响应和中键/命令边界、动画/反馈真实窗口、完整任务/重开、近景/侧面/导航证据。
- [x] 文档：更新相关模块/当前周期/清单与结果，明确静态、构建、运行和视觉边界。

## 所有权与验证约束

粒子与场景对象继续由现有 SceneManager/生命周期设施销毁；相机不持有 Lua 对象；Bullet 刚体仍是对象位置与方向真源，显示插值不得写回物理。动画复用现有骨骼/状态/通知，不引入 root motion。共享工程生成、构建、bin 日志和图形窗口串行运行。Windows 程序路径同步检查，本机无法把它标作运行通过。内部输入证明应用路由与响应，不冒充真人手感。

## 结果记录

本轮按真实窗口迭代，记录以下明确根因和取舍：

1. GL3+ 跳过无 GPU 程序的粒子材质；恢复后旧粒子尺寸又形成过亮光团，已按米制场景缩小并限定发射时长。Bullet 的出生色改为可见色，避免低帧率时在首次 affector 更新前过期。混凝土/地面使用柔边尘屑，装甲/其他表面使用火花；发射点向表面外移2cm避免裁切。Dust 诊断色及有/无纹理单元的连续帧对照确认原 UV 正常；连续 PNG 写盘使粒子自身渲染时钟前进，选择不同帧会错过短寿命效果。多余纹理单元已撤回，最终 8050ms 实机截图可见尘屑。诊断色/错误路径试验保留在 tmp，不作为最终证据。
2. 移动射击原先整身覆盖 fire，AI 停步又有速度阈值；现在停水平运动的合同不依赖 IsMoving，动作通知单次消费，下身按真实速度驱动。横移复核又发现髋旋转传递给上身，补齐 spine 父级空间补偿；保留腿部和髋位移，但上身瞄准不跟侧步旋转。取消/死亡/重建 body 同时清理通知状态。
3. 主动转镜头不再走位置弹簧。遮挡缩距曾使平滑注视点落到镜头后方，导致视线翻转；修为缩距保留视线方向。0.18m球扫掠保护近裁面，立即缩距、平滑返回。
4. 用户在实现中补充“左右转镜头后子弹不随枪口”。确认玩家用独立水平方向覆盖真实枪口，并且挂点在仿真/显示之间滞后；改为当前骨骼求值后的真实枪口发射，渲染插值后同步武器。上下俯仰瞄准不属于这次追加问题。
5. 验证又发现 macOS 后台/回放仍安装硬件监听，先前自然路线出现未记录的方向变化；不能把那些日志当完全隔离输入。现各平台后台或回放都禁用硬件设备，macOS 独立泵窗口事件。另将 Space/左键开火位分离，左键释放不再取消仍按住的 Space。
6. Premake 真源修正 Release 静态归档选择。已重新生成并确认29个实际链接归档均为 Release；主程序 ABI 更新清理的是已核对的生成中间目录。Xcode clean 曾拒绝清理含资源的 bin，未给 bin 添加可删除标记，也未删资源。

## 保留边界

站立侧移仍使用既有crouch侧步资源，尚无专用站立strafe、足底IK或脚底滑移量标定；AI执行比通知晚一个AI tick。P3角色/枪械资产、成套场景细节、PBR光照仍低于目标图。本轮主要改善战斗和操作中的可读性，未把高阶美术差距标完成。
