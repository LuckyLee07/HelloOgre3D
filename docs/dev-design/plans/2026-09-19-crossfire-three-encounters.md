# Crossfire：三场遭遇与体验衔接

日期：2026-09-19。状态：三关技术功能通过；作者确认首次操作不可理解，点击与反馈修订已实现并经原生窗口复核，作者体验复评仍开放。

作者试玩首包后要求“继续后续的升级”，本轮按[重设计草案](../specs/2026-09-19-relay-microgame-design.md)推进 C 阶段的三场手工遭遇与体验衔接。该继续授权不等于作者已认可全部美术、操作或声音品质；后续仍分别记录主观反馈。

## 本轮交付

- 三场遭遇使用同一套机器人与工业设施：维修庭院学习夹击、冷却区学习遮挡绕行、联锁区应对双塔；有实际布局和构图差异。
- 标题/选关、准备阶段的分步提示、结果下一关、全程完成与快速重试；所有关卡可直接练习，最优记录本地保存。
- 设置提供声音和引导开关，独立数据文件保存；不读取或改写旧 Sandbox19 设置。自动验证静音不可被 UI 解除。
- 加强背景设施、场地连接细节和区域标识；现有物理碰撞/导航继续与实景一致，不以换颜色代替不同遭遇。

## 当前结果

- 已实现三场遭遇、标题/选关、分步提示、设置/帮助、下一关、奖章和最优纪录。三关可独立练习，不以解锁强迫顺序。菜单/帮助会冻结战斗，关闭后保持计划，避免意外恢复交火。关闭引导仅隐藏步骤提示，命令结果与失败仍会显示。
- 场景从 15 个独立网格扩为 25 个；三关静态实例分别 79 / 82 / 81。新增接收碟塔、冷却筒、管沟、弯管、后勤台基、实体区域编号；角色及材质套件保持同一方向。世界范围 X±10.35、Z[-12.35,15.8875]；单盏主光跨关复用。
- 第三关从“各打最近目标”转为明确的交叉目标：两机先到前后错开的外侧，再右键指定对側哨卫。初次双塔对照只分路时 19.239 s 仿真后败北；不是简单增加敌人数后照搬首关方案。
- 真实 ShotTrace / ImpactTrace 查明早期对称站位被前方哨卫及残骸拦截。最终右侧站位由 (7,7) 改为 (7,4)，中央纵向掩体置于 (0,2.6)，给实际到达容差留射界。保持实体挡弹，不增加穿透或伪造伤害；独立双塔短回放 10.824 s 胜利，两机存活、108 损伤。
- 指定目标被击毁从错误 failed 改为 completed；输入验证 18 m 武器射程（感知范围 22 m），过远命令给出接近提示。日志保留命令终态、关卡/双塔成绩与切换对象数。
- 独立 Profile 仅解析最多 4096 字节数字数据，按奖章→用时→损伤保存最优值。临时文件完整写入后替换；Windows 有保守备份/回滚流程。保存失败保留内存值，标题/设置提示仅本次生效。设置、记录及临时备份已加入 gitignore；打包不复制开发者成绩。

Windows、真人键鼠与扬声器听感不由内部回放代替。ASCII UI 继续使用现有 Gorilla 字库，中文说明随试玩包提供。

## 作者反馈后的操作修订

作者实际反馈“人工都无法操作”，进一步确认为“点地图没有反应，不知道怎么移动/开火”。旧版以右键下令，左键地面无反馈；无任何计划也能执行，且首轮教程覆盖命令失败提示。这是首次操作设计缺陷，前面的内部回放通过不能将其排除。

通过桌面 UI 自动化在旧包原生窗口复核：开始按钮、右键地面、卡片选机、EXECUTE、自动交火均生效并自然获胜。因此本轮没有改动底层输入桥，也没有将无法复现的底层故障当成根因。

修订限定于 Sandbox20 / HUD：左键地面下移动命令、左键敌人指定目标，保留右键；机器人名称与模型均可选中；顶部改成明确 EXECUTE / PAUSE 按钮；首轮无计划执行时保持暂停并解释下一步；教程旁的独立反馈始终显示排队、失败和执行状态；常驻说明停下自动射击。中文包说明同步为逐步操作。没有改 C++、绑定、物理、射击平衡或旧 sample。

新增 `controls` 门禁把三关流程的鼠标下令全部改为左键，并在首个计划前尝试执行；校验无计划阻止、三关真实胜利、双塔交叉指定、成绩重启和无 Lua 错误。`tmp/crossfire-gate-20260919-133034-ngy78wat/controls/` PASS。随后仅将反馈面板缩到右下角，避免横跨地面；`tmp/crossfire-gate-20260919-133235-myk846db/interface/` 的 960×720 菜单/重试/保存和实际截图通过，地图下方与提示面板无重叠。Lua 5.1 与 `git diff --check` 通过。旧 C++ 构建仍匹配，本轮无需重编。

最终包右键兼容门禁 `tmp/crossfire-gate-20260919-133317-16wyjc2s/natural/` PASS，覆盖右键路线、暂停/恢复、警戒替换、真实胜利与两次重试。

最终包通过桌面 UI 自动化在普通 macOS 1280×720 窗口完成纯左键试玩：点击开始→无计划执行得到明确提示→点被掩体阻挡的敌人标签显示原因→地面给 VEGA 路线→点 ROOK 标签选择→地面设置另一条路线→点 EXECUTE。两机同一 tick=33 接受移动，抵达后自动射击，10.263 s 仿真获胜、两机存活；对局未启用 InputReplay 或 background。界面及日志在本次桌面操作记录中，原生点击重启复验另存 `tmp/crossfire-manual-controls/native-window.log`；测试成绩移出包目录，再留干净首关。

交付为 `tmp/Crossfire-click-controls-20260919-v3/` 及同名 ZIP。源文件一致、签名和 ZIP 完整性通过，ZIP 无测试成绩。操作的作者主观体验、Windows 和人工听感仍不以 UI 自动化替代。

## 三关实际试玩评审

按作者要求于同日用 Computer Use 在普通原生窗口实际操作三关。前两关分别 9.603 / 10.395 s 通关；第三关首次 19.371 s 全灭（88 挡弹、0 侧击），重试交叉目标后击毁一塔，出现约 30.4 s 无伤害僵持，换位后于 53.493 s 败北。发现指定目标与实际拦弹对象未反馈、暂停覆盖关键指引、可见地面与接受范围不一致，以及机器人/护盾/残骸的可读性不足。完整证据和待实施顺序见[实际试玩评审](../reviews/2026-09-19-crossfire-computer-use-review.md)。本次是诊断，没有修改代码或重新打包；不得用既有功能 PASS 代替这些体验缺口已解决。
