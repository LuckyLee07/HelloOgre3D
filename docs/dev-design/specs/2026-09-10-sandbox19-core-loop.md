# Sandbox19 核心玩法一页说明：中继站行动

日期：2026-09-10。已批准的玩法合同。用户已明确反馈：“这套玩法与视觉都非常棒，就按照这套实施吧”。伴随式小队指挥、中继站短任务、浅暖工业场景与紧凑 HUD 已获批准，P1–P3 持续实施，无需再次等待方向确认。完整视觉与技术依据见 [设计稿](2026-09-10-sandbox19-product-experience-design.md)，任务状态见 [backlog](../../backlog.md)，实现与证据见 [当前实现与验收记录](../../playtest-relay-2026-09-10.md)。

## 体验承诺

玩家作为无武器指挥官，与两名自主 AI 队友一同推进小型中继站，通过路线、集火对象和撤回时机改变战斗过程。玩家承担关键选择，AI 承担移动、攻击、换弹与基础自保。保留伴随小队的在场感，扩大可观察范围，降低寻找队友和反复补令的负担。

## 一场任务

**准备 → 门前接敌 → 院区推进 → 清场并集合 → 结算 / 重试。**

- 一张约 48×64 米的单层小地图；一条直接路线、一条由墙体遮挡的侧路，最终通往相同院区。没有必须新建多层导航的路线。
- 初始安全区说明任务与三个命令，玩家主动点击开始；准备期间不开火。
- 首版两个接敌段，每段先以两名敌人为调参起点。后段敌人来自预先可见的前方入口，推进到阶段触发位置才出现，不从玩家背后突兀生成。
- 任务目标：清除全部守卫，让指挥官与至少一名存活队友抵达中继入口集合区。首版不增加交互占点条、成长或装备系统。
- 胜利要求清场和到达均成立；指挥官死亡或两名队友全部阵亡则失败。卡住、超时和不可达单独报告，不传送敌人伪造推进或胜利。
- 结算显示耗时、存活队友、敌人清除数及准确的命令结果；可以重试、返回入口或退出。图中的时间/计数仅为示例。
- 期望提供数次观察和修正机会，可先以数分钟短任务调试，不把固定分钟数作为通过条件；伤害、视距和接敌距离在实测后确定。

## 操作与命令规则

采用较高的第三人称跟随，保留指挥官实体。具体距离、高度与前视参数以当前源码和真实画面验收为准。避免画面长期由天空、角色背部或墙体占据。

| 操作 | 行为合同 | 完成 / 中断 |
|---|---|---|
| 左键 / 拖框；1 / 2；Tab | 单选 / 多选，两张队友卡支持镜头外选人，Tab 全选 | 选中状态与场景标记同步；死亡立即失效 |
| 右键敌人或 F | 集火指定的已知目标 | 目标死亡完成；目标失去可用视野、失效或换令时说明原因并交回自主行为，不用隐藏位置继续追踪 |
| 右键地面；G | 向指定点集结；G 集结到指挥官当前位置，给两人不同落点 | 到达即完成；导航请求失败或持续无进展给出失败反馈；目标位置是下令时快照 |
| T | 撤到已标出的入口安全集合点 | 到达后守住局部区域、不主动追远敌；保持至新命令或取消，不与 G 共用同一种语义 |
| 取消命令 | 明确交回自主行为 | 清掉命令拥有的移动目标和表现，不清他人拥有的状态 |
| WASD、Q/E、滚轮 | 相机平面移动指挥官、调整视角和有限缩放 | 相机与人物转向分开；持续输入手感仍按实际操作验收 |
| Esc | 暂停菜单、设置、重试、退出 | 冻结战斗/波次/命令时钟，UI 仍响应；恢复不突跳 |

命令按自身语义结束，替代统一 8 秒过期。超时仅用于识别卡住等失败，不能静默撤销一个仍正常执行的命令。命令的 `accepted / executing / completed / failed / replaced / cancelled` 状态由实际执行链维护，UI 只读取；图中的确认提示不代表攻击已命中。

## 战术选择与本轮边界

侧路用真实遮挡降低暴露，中央路线更直接；集火改变击杀顺序，撤回保存小队但放弃推进位置。首版没有自动贴掩体、翻越、压制值、特殊兵种或治疗技能，不能用角色站在墙边的画面宣称这些能力存在。自主追击应限定在局部范围内，避免队友自动穿过整张地图。

使用相同版本、布局和 seed，比较不下令、集中火力、侧路集结三种过程。记录首次接敌、目标变化、伤亡、命令结果和导演介入；证明至少一个选择带来可解释差异，不以“指挥必胜”或少量试跑的胜率断言验收。

**已批准方向：伴随式小队指挥 + 中继站短任务 + 浅暖工业场景与紧凑战术 HUD。** 实现不等于验收完成；自然通关、策略比较、多尺寸与独立包的结果见 [当前实现与验收记录](../../playtest-relay-2026-09-10.md)。
