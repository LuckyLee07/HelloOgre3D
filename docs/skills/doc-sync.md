# 文档同步

供 [共享工作流](workflow.md) 或普通实现收尾使用。输入为实际改动和已验证结论，输出为更新文档及未解决项。

直接更新因本次任务失真的相关文档，无固定审批 Gate。没有语义变化就无需文档仪式；不扩展为整个仓库知识库重写。

- 模块能力/接口/约束：命中的 `docs/modules/<alias>.md`；只有 source_paths、约束或验证目标变化时才同步 `docs/registry.json` 对应字段。
- 行为/架构/FGUI：更新对应专项文档；性能结果写 `docs/perf/` 并记录平台、配置、方法和证据。
- 任务进度：按实际验收更新相关 cycle/backlog 或计划；方向变化须来自用户任务，不能因局部实现自行改路线。
- 文档新增/迁移：更新 `docs/README.md` 等现有索引，保留仍有调用者的兼容入口。
- 非显然、跨会话有用且代码未记录的经验：仅写 `docs/memory/` 并更新 `docs/memory/MEMORY.md`，不用根 MEMORY 或工具私有项目真源。

清楚区分静态判断、构建、运行和视觉证据；未完成不标完成。保留用户已有改动。提交仅按 [gitcommit.md](gitcommit.md) 的授权边界执行。
