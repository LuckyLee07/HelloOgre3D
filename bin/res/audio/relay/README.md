# Relay Outpost feedback

Original synthesized PCM 16-bit mono WAV assets, generated deterministically by
`tools/generate_relay_audio.py`. No recordings, music samples, or external assets
were used. These project-authored files may be reused with this project.

The runtime uses one short-sound channel: selection, accepted/rejected orders,
start, pause, result, actual ammunition consumption and health loss. It does not
provide spatial audio or overlapping sound mixing.
